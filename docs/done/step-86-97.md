## 核心目标

Agent 不再只能聊天——它能接收任务、制定计划、搜索网络、编写代码、产出文件。
Worker 模式用**单一协议**（Agent 决策 → 工具执行 → 反馈）替代 Team 模式的 GroupChat+Task 混合架构。

## 架构决策

1. **设计先行。** Phase 22 冻结全部接口，Phase 23-26 只引用不修改。防止 Team 模式"1500 行散落 6 文件"问题。
2. **不复用 WorldEngine/GroupChat。** Worker 单一协议（决策→执行→反馈）。状态机 6 状态 20+ 转换可单测。
3. **Agent 之间不聊天，通过文件沟通。** 文件即接口——避免发言顺序/身份冲突/tick 同步。
4. **JSON 结构化输出。** `{"decision":"tool_call"|"done","tool_name":...}` 格式，解析失败自动重试。
5. **WorkspaceProvider 抽象。** 同一套代码切换本地/云端（SSH），引擎不感知差异。
6. **每 Phase 独立可演示。** Phase 23 即可演示单 Agent 干活。后续 Phase 扩展不回溯核心接口。
