## 关键架构决策

1. **inject_context 双模式** — Arena/Bench 保持 `mode="replace"`，WorldEngine 切 `mode="continuous"`
2. **Tool 生命周期** — AgentFactory 用 stub 创建 agent → WorldEngine.__init__ 注入闭包 tools
3. **副作用去重** — `_handled_actions` 集合防止 tool 闭包和 `_apply_action` 重复生成事件
4. **`_patch_tools` 替代 `replace_tools`** — 不重建 AssistantAgent，保留消息历史
5. **SSE 路径也触发固化** — `plan.all_done` 时调用 `_consolidate_memories` + `_persist_fingerprints`
6. **增量固化 fire-and-forget** — 避免阻塞 SSE 事件流
