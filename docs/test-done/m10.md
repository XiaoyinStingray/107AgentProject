### 数据流

- 评测列表：`useBenchRuns()` → `GET /api/bench/runs`
- 评测详情：`useBenchRun(id)` → `GET /api/bench/runs/{id}`
- 创建评测：`useCreateBenchRun()` → `POST /api/bench/runs`
- 取消评测：`useCancelBenchRun()` → `POST /api/bench/runs/{id}/cancel`
- 劣化检测：`useDegradation()` → `GET /api/bench/degradation`
- 行为指纹：`useBenchFingerprint()` → `GET /api/bench/fingerprint/{agent_id}`
- 分场景统计：`useBenchByScenario()` → `GET /api/bench/by-scenario/{agent_id}`
- Agent 对战：`POST /api/workers/duel` → SSE 事件流

### 六维评分体系

- 人格一致性、决策质量、交互深度、鲁棒性（变异系数）、创造力、适应性
- 鲁棒性使用跨任务变异系数计算（非恒为 100）
- 全 tick 失败仍记为成功但得零分

### 劣化检测规则

- 比较最近 3 次评测 vs 之前 3 次评测
- 综合分下降 >5 分 → 📉 劣化
- 综合分上升 >5 分 → 📈 改进
- 变化 ≤5 分 → ➡️ 稳定

## 4. Bug 记录与修复

### BUG-M10-001（P2）：缺少测试连通按钮

- **现象**：自定义评测区域没有独立的"测试连通"按钮
- **根因**：测试连通功能集成在启动流程中，无独立入口
- **修复**：提取 `handleTestApi()` 函数，新增独立"测试连通"按钮
- **文件**：`frontend/src/pages/BenchLab.tsx`

### BUG-M10-002（P2）：评测结束后仍显示"进行中"

- **现象**：评测完成后界面仍显示"评测进行中"
- **根因**：前端未自动 refetch 已完成状态的 run 详情
- **修复**：添加 `useEffect` 检测 `run.status !== "running"` 时自动 `refetchDetail()`，加手动刷新按钮
- **文件**：`frontend/src/pages/BenchLab.tsx`

### BUG-M10-003（P2）：侧边栏排行榜点击不跳转

- **现象**：点击侧边栏"排行榜"URL 变化但页面不导航
- **根因**：锚点 `#leaderboard` 对应的 DOM 元素不存在时无回退
- **修复**：目标元素不存在时回退滚动到 `#runs`
- **文件**：`frontend/src/pages/BenchLab.tsx`

### BUG-M10-004（P2）：模板套用后无回应

- **现象**：点击"套用"模板后无反应
- **根因**：`applyTemplate` 使用 Agent ID 直接设置，但模板中的 Agent 可能不存在
- **修复**：过滤有效 Agent/场景 ID，提示跳过项数量
- **文件**：`frontend/src/pages/BenchLab.tsx`

### BUG-M10-005（P2）：自定义套件启动键无回应

- **现象**：自定义评测"启动"按钮点击无效果
- **根因**：与 Bug 004 同源，配置无效时静默失败
- **修复**：同 Bug 004 修复，增加 `setMsg` prop 传入 CustomSuitePanel
- **文件**：`frontend/src/pages/BenchLab.tsx`

### BUG-M10-006（P2）：趋势图缺坐标轴和数据标签

- **现象**：趋势折线图无 Y 轴刻度、无网格线、数据点无分值标注
- **根因**：SVG 渲染区域只有折线和点，缺少辅助元素
- **修复**：添加 Y 轴网格线（0/25/50/75/100）、刻度标签、数据点上方分值
- **文件**：`frontend/src/pages/BenchLab.tsx`

### BUG-M10-007（P2）：Agent 对战平局文案和 ID 显示

- **现象**：平局显示"胜者：平局"，对战结果使用 Worker ID 而非 Agent 名称
- **根因**：文案拼接逻辑未处理 draw 情况；`_get_or_create_agent` 用 `Worker-{id[:8]}` 命名
- **修复**：draw 时显示"平局"而非"胜者: 平局"；从数据库查询 Agent 真实名称
- **文件**：`frontend/src/pages/DuelArena.tsx`、`backend/src/api/workers.py`

### BUG-M10-008（P2）：窄屏溢出无滚动条

- **现象**：窄屏幕下内容溢出，无法水平滚动
- **根因**：SVG 趋势图使用固定宽度，容器无 overflow 处理
- **修复**：SVG 改用 `viewBox` 响应式 + 容器 `overflow-x-auto`
- **文件**：`frontend/src/pages/BenchLab.tsx`

### BUG-M10-009（P2）：趋势图 Y 轴刻度与数据不对应

- **现象**：56 分的点显示在 100 刻度线附近
- **根因**：`maxS` 取数据最大值（如 57），导致 56/57 ≈ 98% 位置
- **修复**：改为固定 `MAX_SCORE = 100`
- **文件**：`frontend/src/pages/BenchLab.tsx`

### BUG-M10-010（P2）：自定义评测快速失败/指标全零

- **现象**：自定义 Agent 评测用时极短，所有指标为零
- **根因**：`_run_single_test` 直接访问 `agent_tpl["mbti"]` 等字段，自定义 Agent 缺少这些字段导致 KeyError → catch → 零分
- **修复**：改用 `.get()` 提供默认值（mbti→INTJ, big_five→均衡值, narrative→Agent 名+描述, decision_style→综合分析型）
- **文件**：`backend/src/engines/bench/scheduler.py`

### BUG-M10-011（P2）：评测启动提示不消失

- **现象**：评测启动后"评测已启动"提示持续显示
- **根因**：`setMsg` 后无自动清除逻辑
- **修复**：启动成功后 `setTimeout(() => setMsg(null), 3000)` 3 秒自动消失
- **文件**：`frontend/src/pages/BenchLab.tsx`

### BUG-M10-012（P2）：劣化检测面板不易懂

- **现象**：劣化检测面板只有标题和数据，无说明文字
- **根因**：缺少功能说明
- **修复**：添加说明文字：「对比最近 3 次 vs 之前 3 次评测，综合分下降 >5 分标记为 📉 劣化，上升 >5 分为 📈 改进，变化 ≤5 分为 ➡️ 稳定」
- **文件**：`frontend/src/pages/BenchLab.tsx`

### BUG-M10-013（P2）：对战结果含 Worker ID

- **现象**：对战结果 summary 中显示 `Worker-06f09bef` 等 ID
- **根因**：`_get_or_create_agent` 找不到 Agent 时用 `Worker-{id[:8]}` 作为名字
- **修复**：先从数据库 `AgentRow` 查询真实名称，查不到才回退 Worker 命名
- **文件**：`backend/src/api/workers.py`

### BUG-M10-014（P2）：web_search 搜索无结果

- **现象**：Agent 对战的 web search 阶段出现搜索无结果
- **根因**：环境配置问题（DeepSeek Responses API / Bing / DuckDuckGo 三者均失败）
- **状态**：非代码 Bug，属环境配置问题

### BUG-M10-015（P2）：自定义评测无 API Key 时启动键未禁用

- **现象**：未输入 API Key 时仍可点击启动
- **根因**：CustomSuitePanel 启动按钮 disabled 条件未检查 apiKey
- **修复**：将 apiKey 作为 prop 传入，disabled 条件添加 `!apiKey`
- **文件**：`frontend/src/pages/BenchLab.tsx`

### BUG-M10-016（P2）：自定义评测仍全部零分

- **现象**：Bug 010 修复后仍有零分情况
- **根因**：`calculate_metrics` 调用处仍使用 `agent_tpl["mbti"]` 直接访问
- **修复**：改用已定义的 `_mbti` 和 `_big_five` 变量（含默认值）
- **文件**：`backend/src/engines/bench/scheduler.py`

### BUG-M10-017（P2）：劣化检测柱状图太矮/无数值标注

- **现象**：柱状图高度太矮看不清，且无具体数值标示
- **根因**：容器 `h-8`（32px）太矮，柱子无数值标注
- **修复**：改为 `h-24`（96px），每根柱子顶部显示具体分数，最小柱高 8%
- **文件**：`frontend/src/pages/BenchLab.tsx`

### 其他 UI 修复

- **Dashboard 响应式布局**：快捷入口改为 `grid-cols-2 sm:grid-cols-3 md:grid-cols-4 lg:grid-cols-6`，Agent 列表改为 `grid-cols-1 sm:grid-cols-2 lg:grid-cols-3`
- **功能名称文字截断**：移除 `truncate`，添加 `break-words` + `leading-tight` + `shrink-0`
- **文件**：`frontend/src/pages/Home.tsx`
