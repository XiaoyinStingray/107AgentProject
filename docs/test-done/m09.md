### 数据流

- Team 创建：`POST /api/teams` → `TeamRow` + `roles` 映射
- 任务执行：`POST /api/teams/{id}/execute` → `PlanRow` → `TeamEngine.execute()` → SSE 事件流
- 报告生成：`engine._compile_report()` → Markdown → `PlanRow.report`
- 文件下载：前端从报告正文正则提取内容 → Blob 本地下载
- Team 对抗：`POST /api/teams/versus` → LLM 对比两队的报告 → 8 维度评分
- 学习画像：`GET /api/teams/{id}/learning_curve` → `compute_learning_curve()` → 完成率趋势
- LLM 评分：`POST /api/teams/{id}/score` → LLM 多维评分 → 完整性/创新性/可行性等 8 维度
