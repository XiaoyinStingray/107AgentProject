## 4. Bug 记录与修复

### BUG-044（P0）：P3 叙事端点参数错误

- **现象**：microfilm/serial/selfportrait 三种风格全部 500 错误
- **根因**：`narratives.py` 三个端点调用 `_generate_narrative(req, Style)` 参数顺序错误且缺少 db/engine 依赖注入
- **修复**：三个端点改为标准模式——添加 `Depends(get_db)` 和 `Depends(get_narrative_engine)`，参数顺序修正
- **文件**：`backend/src/api/narratives.py`

### BUG-045（P2）：isPending 和 handleGenerate 依赖不完整

- **现象**：P3 风格生成时按钮不显示加载态，用户可重复点击
- **根因**：`isPending` 只检查前 5 种风格，`handleGenerate` 依赖数组缺少 P3 mutations
- **修复**：补充 `generateMicrofilm/generateSerial/generateSelfportrait` 到 isPending 和依赖数组
- **文件**：`frontend/src/pages/NarrativeFactory.tsx`

### BUG-046（P2）：日记风格无独立标题

- **现象**：标题为正文第一句，没有独立标题
- **根因**：DIARY_PROMPT 缺少 `标题：<标题>` 格式返回指令
- **修复**：模板添加标题格式指令，要求「标题用日期或主题，正文以今天...开头」
- **文件**：`backend/src/engines/narrative/templates.py`

### BUG-047（P2）：信件风格标题为称呼语

- **现象**：标题为「亲爱的未来的自己：」等称呼语
- **根因**：LETTER_PROMPT 缺少标题格式返回指令
- **修复**：模板添加标题格式指令，要求「标题自拟，不要用称呼作标题」
- **文件**：`backend/src/engines/narrative/templates.py`

### BUG-048（P1）：播客/平行对话生成内容偏离用户输入的主题

- **现象**：输入主题「豆腐脑是甜的还是咸的」，输出标题和内容完全无关
- **根因**：PODCAST_PROMPT 和 PARALLEL_PROMPT 只把 target 当「信息」列出，未强制围绕主题写
- **修复**：两个模板添加「标题必须包含/反映主题，不得偏离」「内容必须围绕主题展开」；格式指令提到要求之前并加强语气
- **文件**：`backend/src/engines/narrative/templates.py`
