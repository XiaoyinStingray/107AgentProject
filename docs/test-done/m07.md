### 事件注入功能详情

**4 种注入类型**：
- `world_event`：世界事件（不需要目标 Agent）
- `agent_message`：Agent 消息（需要目标 Agent）
- `agent_action`：Agent 行动（需要目标 Agent）
- `relationship_change`：关系变化（需要两个 Agent）

**后端链路**：
`POST /api/worlds/{id}/inject` → `WorldEngine.inject_event()` → `_pending_injects` 队列 → SSE 推送

**注入隔离机制**：
- `_recent_events_text()` 过滤 `injected=True` 的事件，不出现在共享上下文
- `_inject_world_context()` 只为目标 Agent 添加私有提示
- `SelectorGroupChat` 每次 tick 新建，task 不包含 `self.events`

### 数据流

- World 列表：`useWorlds()` → `GET /api/worlds`（过滤 running/paused，排除 Team:/Scene: 前缀）
- Agent 列表：`useAgents()` → `GET /api/agents`（按选中 World 的 `agent_ids` 过滤）
- 干预历史：`useWorldInterventions(worldId)` → `GET /api/worlds/{id}/interventions`
- 注入操作：`useInjectEvent()` → `POST /api/worlds/{id}/inject`

## 4. Bug 记录与修复

### BUG-M7-001（P1）：Agent 选择未按 World 过滤

- **现象**：事件注入表单显示所有 Agent，而非选中 World 的 Agent
- **根因**：`DirectorIntervention.tsx` 未根据 `selectedWorld.agent_ids` 过滤 Agent 列表
- **修复**：添加 `worldAgents` 过滤逻辑
- **文件**：`frontend/src/pages/DirectorIntervention.tsx`

### BUG-M7-002（P2）：切换事件类型时 Agent 选择未重置

- **现象**：切换事件类型后，之前选择的 Agent 仍然保留
- **根因**：类型切换时未清空 `targetAgentId` 和 `targetAgentId2`
- **修复**：在类型切换回调中添加 `setTargetAgentId("")` 和 `setTargetAgentId2("")`
- **文件**：`frontend/src/pages/DirectorIntervention.tsx`

### BUG-M7-003（P2）：Agent 点击两次应取消选择

- **现象**：点击已选中的 Agent 无法取消选择
- **根因**：点击回调只有选中逻辑，缺少 toggle 逻辑
- **修复**：添加 `isSelected ? "" : agent.id` 的 toggle 逻辑
- **文件**：`frontend/src/pages/DirectorIntervention.tsx`

### BUG-M7-004（P2）：关系变化无法选择两个 Agent

- **现象**：关系变化类型只能选择一个 Agent
- **根因**：缺少第二个 Agent 选择器和 `target_agent_id_2` 参数
- **修复**：新增 `targetAgentId2` 状态、第二个选择器、API 传递 `target_agent_id_2`
- **文件**：`frontend/src/pages/DirectorIntervention.tsx`、`frontend/src/api/worlds.ts`

### BUG-M7-005（P1）：Agent 消息注入所有人回应 + 来源显示异常

- **现象**：注入的 agent_message 被所有 Agent 回应，来源显示为 "." 或空
- **根因**：
  1. 注入事件未正确标记来源
  2. 前端未显示目标 Agent 名称
- **修复**：
  1. 后端 `sse.py` 设置 `display_name = "world"` 对于注入事件
  2. 前端显示 `target_names`（目标 Agent 名称列表）
  3. 后端验证注入隔离机制正确（`_recent_events_text()` 过滤 + `_inject_world_context()` 私有提示）
- **文件**：`backend/src/api/sse.py`、`frontend/src/components/agent/ThoughtBubble.tsx`

### BUG-M7-006（P2）：M3 消息类型颜色应对应

- **现象**：ThoughtBubble 和 EventFeed 的颜色方案不一致
- **根因**：两个组件使用不同的颜色配置
- **修复**：统一颜色方案（agent_message→绿色、agent_action→橙色）
- **文件**：`frontend/src/components/agent/ThoughtBubble.tsx`

### BUG-M7-007（P2）：M2/M3 鼠标滚轮滚动跳到底部

- **现象**：用户手动上滚后，新事件到达时仍然跳到底部
- **根因**：自动滚底逻辑未检测用户是否手动上滚
- **修复**：添加 `userScrolledUp` 状态，仅在用户接近底部时自动滚底
- **文件**：`frontend/src/components/world/EventFeed.tsx`、`frontend/src/components/world/Timeline.tsx`

### BUG-M7-008（P2）：ThoughtBubble 字体颜色与 EventFeed 不对应

- **现象**：ThoughtBubble 和 EventFeed 的颜色方案不一致
- **根因**：两个组件使用不同的颜色配置
- **修复**：统一颜色方案（agent_message→紫色、agent_action→绿色）
- **文件**：`frontend/src/components/agent/ThoughtBubble.tsx`、`frontend/src/components/world/EventFeed.tsx`

### BUG-M7-009（P2）：群体沙盒显示 DSML 代码样文字

- **现象**：对话气泡中出现 `<||DSML||tool_calls>` 等代码样文字
- **根因**：前端未过滤 DSML 标签
- **修复**：在 `stripInternalMarkers()` 和 `formatEventDescription()` 中添加 DSML 标签过滤正则
- **文件**：`frontend/src/components/agent/ThoughtBubble.tsx`、`frontend/src/components/world/EventFeed.tsx`

### BUG-M7-010（P2）：Agent 消息来源为空（注入事件）

- **现象**：注入的 agent_message 来源显示为空
- **根因**：前端使用 `??` 而非 `||`，空字符串未回退到默认值
- **修复**：将 `??` 改为 `||`，确保空字符串也能回退

### BUG-M7-011（P2）：给 A 发的消息其他人却在回应
