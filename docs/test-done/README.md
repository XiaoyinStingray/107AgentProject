## 状态图例

| 符号 | 含义 |
|------|------|
| ⬜ | 未开始 |
| 🚧 | 进行中 |
| ✅ | 已完成 |
| ⚠️ | 受阻/有已知问题 |
| 🔄 | 需要回溯修改 |
| 🔀 | 此模块被后续步骤修改过 |

### 状态更新规则

- 进入模块级 READ 后，将状态改为 🚧。
- 存在阻断或已知缺陷时使用 ⚠️，不得同时视为完成。
- 后续修改可能影响已测模块时先使用 🔀，完成影响评估后转为 🔄 或恢复 ✅。
- 只有机器测试、手测、Bug 回归、人工验收和 `mNN.md` 全部完成后才能使用 ✅。
