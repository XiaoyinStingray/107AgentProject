### 数据流

- 模拟回放：`useSimulations()` → `GET /api/simulations`
- 回放详情：`useSimulation(id)` → `GET /api/simulations/{id}`
- 成就系统：`useAchievements()` → `GET /api/achievements`（后端 10 个 + 前端 16 个合并 = 26 个）
- 报告导出：`useExportReport()` → `GET /api/export/report/{world_id}`（MD）或 `/json`
- URL 状态：`?replay=world_id`（回放展开）、`#highlights/#templates/#achievements/#export`（Tab 切换）

### 成就合并逻辑

- 后端 `GET /api/achievements` 返回 10 个基础成就（含进度计算）
- 前端 `game/achievements.ts` 定义 16 个跨模块成就（平台/M9/M10/M11/M12）
- `AchievementsPanel` 合并去重后共 26 个成就
- ach-10（全能选手）进度在前端合并后重新计算（分母 = 25，除自身外其他成就）

## 4. Bug 记录与修复

### BUG-M8-001（P2）：回放缺少消息类型图例

- **现象**：回放事件列表显示图标（💬💭🎬📌）但无图例说明
- **根因**：事件列表渲染区域缺少图例行
- **修复**：在事件列表上方添加图例行（对话/思考/行动/世界/其他）
- **文件**：`frontend/src/pages/Archive.tsx`

### BUG-M8-002（P2）：#highlight URL hash 无法定向到回放

- **现象**：在 M8 其他功能下输入 URL `#highlight` 无法定向到精彩回放 Tab
- **根因**：`Archive.tsx` 的 hash→tab 映射缺少 `highlights` 键
- **修复**：在 MAP 中添加 `highlights: "highlights"`
- **文件**：`frontend/src/pages/Archive.tsx`

### BUG-M8-003（P2）：World 暂停后回放未立即拉取

- **现象**：从 World 切换到精彩回放后，World 自动暂停，但回放不会立即拉取最新事件
- **根因**：轮询逻辑只在 `running` 状态下工作，状态变为 `paused` 时直接返回
- **修复**：用 `prevStatusRef` 检测状态从 `running` 变为 `paused` 时立即执行一次 `handleRefresh()`
- **文件**：`frontend/src/pages/Archive.tsx`

### BUG-M8-004（P2）：展开回放后 URL 不变化

- **现象**：点开模拟回放记录后 URL 不会变化，无法分享特定回放链接
- **根因**：`handleToggleReplay` 未更新 URL search params
- **修复**：展开时添加 `?replay=world_id`，收起时清除该参数（使用 `navigate` + `replace`）
- **文件**：`frontend/src/pages/Archive.tsx`

### BUG-M8-005（P2）：成就进度条和百分比不对应

- **现象**：进度条宽度和显示百分比因浮点精度不一致
- **根因**：进度条用 `Math.min(100, ach.progress * 100)`，百分比用 `Math.round(ach.progress * 100)`
- **修复**：统一使用 `Math.round(ach.progress * 100)` 计算
- **文件**：`frontend/src/pages/Archive.tsx`

### BUG-M8-006（P2）：导出报告命名/Agent 过滤/事件类型中文

- **现象**：(1) 文件名使用 hash 而非 World 名称；(2) 参与 Agent 列出全部而非仅参与者；(3) 事件分布使用英文类型名
- **根因**：`_ascii_slug` 生成 hash 文件名；`_collect_agent_names` 返回全部 Agent；事件类型未映射中文
- **修复**：
  1. 文件名格式改为 `report-{场景名}-{世界名}-{日期}`（清理非法字符）
  2. 过滤只保留 events 中实际出现的 agent_id
  3. 添加 `_TYPE_CN` 映射表（agent_message→对话、thought_stream→思考等）
  4. Content-Disposition header 使用 RFC 5987 UTF-8 编码（`filename*=UTF-8''{quote(filename)}`）
- **文件**：`backend/src/api/export.py`

### BUG-M8-007（P2）：宽度缩小后布局不合理

- **现象**：成就卡片在中等宽度下显示 2 列太窄
- **根因**：`grid-cols-2 md:grid-cols-5` 断点跳跃太大
- **修复**：改为 `grid-cols-2 sm:grid-cols-3 lg:grid-cols-5` 渐进式断点
- **文件**：`frontend/src/pages/Archive.tsx`

### BUG-M8-008（P2）：统计卡片响应式布局

- **现象**：成就系统上方 4 个统计卡片在宽度缩小时不换行
- **根因**：`grid-cols-4` 没有响应式断点
- **修复**：改为 `grid-cols-2 sm:grid-cols-4`
- **文件**：`frontend/src/pages/Archive.tsx`

### BUG-M8-009（P2）：全能选手进度计算错误

- **现象**：ach-10 进度显示 67%（6/9），但前端合并后有 26 个成就
- **根因**：后端只计算 10 个基础成就的进度（分母 9），未考虑前端补充的 16 个
- **修复**：在前端合并成就后重新计算 ach-10 进度（分母 = 25，除自身外其他成就）
- **文件**：`frontend/src/pages/Archive.tsx`

### BUG-M8-010（P2）：P3 占位 Tab 未显示

- **现象**：Agent 市场、社区数据大屏、API 开放 3 个 P3 Tab 未显示
- **根因**：`ARCHIVE_TABS` 只定义了 4 个 P2 Tab
- **修复**：添加 3 个 P3 占位 Tab（`available: false`，灰色不可点击）
- **文件**：`frontend/src/mocks/archive.ts`
