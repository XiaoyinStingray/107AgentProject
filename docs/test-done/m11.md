## 4. Bug 记录与修复

### BUG-M11-001（P2）：存档面板暂停按钮文字歧义

- **现象**：添加 Agent 后存档状态显示"暂停"但人物在行动，用户误以为场景已暂停
- **根因**：按钮文字 "⏸ 暂停" 被理解为状态描述而非动作按钮
- **修复**：按钮改为 "⏸ 暂停场景" / "▶ 继续场景"，状态改为 "⏸ 已暂停" / "▶ 运行中"
- **文件**：`frontend/src/components/scene/CheckpointPanel.tsx`

### BUG-M11-002（P2）：Agent 发言含 DSML 标签代码文字

- **现象**：Agent 对话中偶尔出现 `<||` 等 DSML 格式标签
- **根因**：`generate_dialogue_llm()` 缺少 DSML 清洗（ ThoughtStream/EventFeed 已修复但场景对话端点遗漏）
- **修复**：后端新增 `_clean_dsml()` 正则清洗函数，在 LLM 输出返回前过滤
- **文件**：`backend/src/engines/scene/engine.py`

### BUG-M11-003（P2）：搭话选项固定不契合对话内容

- **现象**：无论 Agent 说什么，回复选项总是"聊啊/随便/太闲了"
- **根因**：`pickTopic()` 类别推断关键词过少，大量话题归入 "chat" 类别；chat 选项池仅 2 套
- **修复**：扩展 invite 关键词（想听/想看/想知/好吗/愿意/陪你/带你），调整检查优先级，chat 池增至 3 套，invite 池增至 4 套
- **文件**：`frontend/src/game/ProactiveChatManager.ts`、`frontend/src/game/dialogue.ts`

### BUG-M11-004（P2）：耳语后 Agent 重复说同样的话

- **现象**：耳语后 Agent 反复说相同的对话
- **根因**：mock 防重复窗口只记录最近 1 条索引
- **修复**：防重复窗口从 1 条扩大到最近 3 条
- **文件**：`frontend/src/game/dialogue.ts`

### BUG-M11-005（P2）：对话消息泡泡消失太快

- **现象**：Agent 对话气泡 2.5 秒就消失，用户来不及读完
- **根因**：ActionBubble 固定 2500ms 淡出
- **修复**：动态时长 `max(3500, 1800 + 字数×60)` ms，短文本最少 3.5 秒
- **文件**：`frontend/src/game/sprites/ActionBubble.ts`

### BUG-M11-006（P2）：长时间没人说话

- **现象**：Agent 分散在地图上时长时间不触发对话
- **根因**：PROXIMITY=5 太严 + COOLDOWN=8s 太长
- **修复**：PROXIMITY 5→7，COOLDOWN 8s→5s
- **文件**：`frontend/src/game/scenes/MapScene.ts`

### BUG-M11-007（P2）：涂鸦指令有时失效

- **现象**：画线/画圈/画叉有时无法识别
- **根因**：识别阈值过严（MIN_POINTS=10, LINE_MAX_DEVIATION=15, CIRCLE_MIN_ROUNDNESS=0.6）+ 失败无反馈
- **修复**：放宽 6 项阈值 + 识别失败时显示淡灰色笔画提示
- **文件**：`frontend/src/game/effects/GraffitiLayer.ts`

### BUG-M11-008（P2）：LLM 对话选项生成不生效

- **现象**：搭话回复选项始终为硬编码模板，LLM 生成未生效
- **根因**：`scenes.py` 的 `create()` 调用传了 `temperature`/`max_tokens` 参数（AutoGen 不支持）且使用 plain dict 而非 `UserMessage` 对象
- **修复**：移除不支持的参数，改用 `UserMessage(content=..., source=...)`，`result.content` 加 `str()` 转换
- **文件**：`backend/src/api/scenes.py`

### BUG-M11-009（P2）：对话选项不随对话进展更新

- **现象**：Agent 每说一句话后选项仍为初始选项，不贴合最新对话内容
- **根因**：选项只在弹窗打开时生成一次，后续轮次未刷新
- **修复**：`chat-options` 端点增加 `history` 参数；ProactiveChat 每轮 Agent 回应后自动调用 LLM 刷新选项
- **文件**：`backend/src/api/scenes.py`、`frontend/src/game/dialogue.ts`、`frontend/src/components/scene/ProactiveChat.tsx`、`frontend/src/pages/GameScene.tsx`

### BUG-M11-010（P2）：正面 emoji 投掷也会触发"友尽"

- **现象**：投 ❤️/🌸/🎵 多次后 Agent 也出现"友尽"不回应
- **根因**：所有 emoji 命中都计入友尽计数器
- **修复**：区分正面/负面 emoji，只有负面 emoji（😡/💣/👻）计入友尽计数
- **文件**：`frontend/src/game/effects/EmojiDrop.ts`
