## 4. Bug 记录与修复

### BUG-M6-001（P1）：M2 单人剧场 `[END_TICK]` 泄漏到显示内容

- **现象**：对话气泡中出现 `[END_TICK]` 文字
- **根因**：`_clean_group_content()` 只在 group chat 路径（`_convert_message_to_event`）调用，solo theater 的 `_inner_message_to_event` 和 `_final_message_to_event` 直接传 `str(content)` 未清理
- **修复**：
  1. 后端 `messages.py`：两个方法添加 `_clean_group_content()` 调用 + 空内容守卫（`if not cleaned: return None`）
  2. 前端 `ThoughtBubble.tsx`：新增 `stripInternalMarkers()` 防御性过滤 `[END_TICK]` 和工具调用残留
  3. 前端 `EventFeed.tsx`：`formatEventDescription` 同样添加 `stripMarkers` 防御
- **文件**：`backend/src/engines/world/messages.py`、`frontend/src/components/agent/ThoughtBubble.tsx`、`frontend/src/components/world/EventFeed.tsx`

### BUG-M6-002（P2）：仪表盘 Agent 精力全部显示 100%

- **现象**：所有 Agent 精力条满格，实际应低于 100%
- **根因**：`computeAgentStats` 直接取 `agent.energy`（数据库值始终 100.0），未应用衰减公式。`AgentStatusPanel` 有前端衰减但 `computeAgentStats` 没有
- **修复**：`mocks/control.ts` 添加与 `AgentStatusPanel` 一致的衰减公式 `Math.max(10, agent.energy - Math.floor(events.length / 5) * 2)`
- **文件**：`frontend/src/mocks/control.ts`

### BUG-M6-003（P1）：修复后 `[END_TICK]` 仍出现 + 搜索/决策模式受 World 过滤影响

- **现象**：
  1. 后端空内容守卫生效但旧事件已持久化，`[END_TICK]` 仍在前端渲染
  2. Agent 搜索和决策模式 Tab 只显示选中 World 的 Agent，应展示全部
- **根因**：
  1. 后端修复只阻止新事件，旧事件已在数据库中
  2. `ControlPanel.tsx` 将 `filteredAgents` 传给了所有 Tab，包括不需要 World 过滤的搜索和决策模式
- **修复**：
  1. 前端 `ThoughtBubble.tsx` + `EventFeed.tsx` 加防御性 `stripInternalMarkers`（已在 BUG-M6-001 中完成）
  2. `ControlPanel.tsx`：`AgentSearch` 和 `DecisionPatterns` 改回使用 `agents`（全部 Agent）
- **文件**：`frontend/src/pages/ControlPanel.tsx`

### BUG-M6-004（P1）：单人剧场行动事件（agent_action）不渲染

- **现象**：单人剧场只显示对话气泡，思考和行动气泡全部消失
- **根因**：`ThoughtBubble.tsx` 的 `resolveBodyText` 处理 `agent_action` 时只从 `event.data` 中找 `thought`/`description`/`content`/`target`，但后端 `_tool_call_to_event` 把可读描述放在 `event.description`（如 "观察: 教室"）。对于 `observe`、`set_goal` 等工具，`data` 中没有对应字段，导致 `bodyText` 为空 → 被 `if (!bodyText) return null` 跳过
- **修复**：`resolveBodyText` 的 `agent_action` 分支在 `data` 字段提取失败后，回退到 `event.description`
- **文件**：`frontend/src/components/agent/ThoughtBubble.tsx`
