# M12 Worker 工作台 — 模块测试记录

## 模块概述

M12 Worker 工作台是项目最后一个功能模块，核心是 AgentWorker 引擎——状态机驱动的单 Agent 决策循环 + 工具执行 + SSE 事件流。

**功能项**（#60-#67，共 8 项）：
1. AgentWorker 引擎（状态机 + 决策循环 + 工具执行）
2. WorkspaceProvider 双轨工作区（Local + Cloud SSH/SFTP）
3. 工具系统（6 基础 + 8 特殊工具）
4. 配方系统（5 个预设配方 + phase 推进）
5. 决策分叉（快照恢复 + 候选路线生成）
6. 管道编排（DAG 拓扑 + 并行执行 + FLOW/LOOP/BRANCH）
7. 自主调度（Cron 定时 + 文件监视）
8. 交付验收（确定性硬校验 + LLM 独立验收 + 自动修订）

## Bug 发现

机器测试阶段未发现 Bug。人工验收发现 7 个问题，全部修复：

| # | 问题 | 根因 | 修复 |
|---|------|------|------|
| 1 | 文件预览窗口太小 | WorkspacePanel 使用 `absolute inset-0` 内嵌面板 | 改为 `fixed inset-4` 悬浮全屏弹窗 + 遮罩层 |
| 2 | 查看历史时正在执行的任务停止 | `hydrate()` 调用了 `abortRef.current?.abort()` 中断 SSE | 移除 abort 调用，仅更新状态 |
| 3 | 决策分叉执行后面板未折叠 | 缺少 connected 状态联动 | 添加 `useEffect` 监听 `connected` 自动折叠 |
| 4 | 前端无配方选择 UI | 后端已有 `/api/workers/recipes` 和 `recipe_id` 字段，但前端未对接 | 添加配方下拉选择器 + `buildRequest` 传入 `recipe_id` |
| 5 | web_search 经常无结果 | DDG Instant Answer API 对普通搜索词返回极少结果 | 新增 `_ddg_html_search` 解析 DDG lite HTML 页面作为最终 fallback |
| 6 | web_search 多次无结果时反复超时 | 6 个引擎串行尝试，每次失败需 62s；agent 换关键词又重试 | 全局断路器（连续 3 次失败后断路 5 分钟）+ 并行 fallback + 超时缩短至 15+5s |
| 7 | 切换页面后执行中任务卡住不动 | 组件卸载丢失 SSE 连接，返回后只 hydrate 历史事件但未重连 | 新增 `/events/stream` SSE 端点 + `resubscribe()` 方法，reconnect effect 自动恢复 |
